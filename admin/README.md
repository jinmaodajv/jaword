# jaword-vue-admin

> 这是一个日语词汇学习系统的管理后台。它是基于vue-admin-template框架进行的二次开发。

## Build Seup

```bash
# 克隆项目
git clone https://github.com/jinmaodajv/jaword.git

# 进入项目目录
cd jaword-vue-admin

# 安装依赖
npm install

# 建议不要直接使用 cnpm 安装以来，会有各种诡异的 bug。可以通过如下操作解决 npm 下载速度慢的问题
npm install --registry=https://registry.npm.taobao.org

# 启动服务
npm run dev
```

浏览器访问 [http://localhost:9528](http://localhost:9528)
